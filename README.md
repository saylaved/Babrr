# L.A. Barbershop — Next.js prototype

Односторінковий сайт L.A. Barbershop (ЖК Комфорт таун, Київ). Вміст і ціни перенесені з переданого архіву сайту; дизайн та компоненти переосмислені під Next.js, Tailwind CSS v4 і Framer Motion.

## Запуск

Потрібен Node.js 20+ та встановлені залежності проєкту. Після підготовки середовища:

```bash
npm run dev
```

Відкрийте `http://localhost:3000`. Production-команди: `npm run build`, `npm start`, `npm run typecheck`.

> У середовищі створення проєкту немає Next.js, Tailwind CSS або Framer Motion у локальному кеші, а мережевого доступу немає. Тому залежності не встановлювалися й production build тут не запускався.

## Що зроблено

- Адаптивний головний екран, українська локаль, окремі стани мобільної навігації та desktop-навігації.
- П’ять майстрів із фотографіями, рейтингами, кількістю відгуків, цінами й прямими посиланнями на їхні сторінки запису.
- Три рівні прайсу; URL-параметр `?level=top|barber|junior` зберігає вибір.
- Запис іде напряму у вихідний Altegio — другого джерела обліку записів немає.
- Локальний photo-demo для підбору форми обличчя. Фото обробляється у вкладці браузера, не завантажується й не зберігається. Результат — евристична пропозиція за пропорціями файла, не AI-розпізнавання та не рекомендація фахівця.
- Окремо вказані адреса, карта, графік, відсутність передоплати та джерело snapshot цін.
- SEO metadata, JSON-LD `BarberShop`, власна іконка, self-hosted на стороні Next.js шрифти.
- Рух: реактивне поле «фейду» в canvas (короткий рух лише під курсором), scroll-переходи, pinned-галерея, живий прайс, локальні переходи, магнітні кнопки та автопрокрутка відгуків із керуванням.
- Доступність: український `lang`, skip link, видимий фокус, семантична навігація, tab/arrow-key interaction, статуси через live region, `prefers-reduced-motion`, safe-area для нижнього мобільного доку.

## Візуальна система

Концепція — **«точність фейду»**: насадки #0–#4 стають шкалою, а послідовність тонких ліній у Hero повторює градацію від чистого зрізу до довшого волосся. Це одна головна графічна метафора замість декору з кліше барбершопів.

- **Кольори:** чорний `#000000`, графіт `#1A1C1F`, правило `#2B2E33`, сталь `#8E949C`, хром `#E6E8EB`, крейда `#EEF0F2`; сигнальний червоний `#D0312D` використовується лише для позначення п’яти оцінок нижче п’яти зірок.
- **Шрифти:** Unbounded для коротких дисплейних заголовків та Onest для інтерфейсу/довгого тексту; обидва з кирилицею.
- **Композиція:** темне поле, великі відступи, фактична інформація замість маркетингових обіцянок; світлий прайс як єдина велика зміна поверхні.
- **Рух:** анімації пояснюють дію або дані; нескінченний motion не використовуємо для кожної картки. Поважаємо системне зменшення руху.

## Дані й межі готовності

Джерело даних у переданому сайті позначено як публічна онлайн-запис Altegio, snapshot від 10.11.2026. Числа збережені. Перед релізом власник має звірити дату snapshot, ціни, формулювання відгуків, адресу й бронювання з живим профілем Altegio. Зміна цін вручну виконується в `lib/data.ts`; наступний крок — серверне читання `book_services` / `book_staff` з коротким кешем, не клієнтський запит.

Це source-проєкт для локального запуску, не production-deploy: не надані домен/канонічний URL, інтеграційні креденшіали, API-власник і підтверджений production snapshot. Пошук форми обличчя навмисно позначений beta та евристичним, щоб не видавати mock за працюючий AI.
